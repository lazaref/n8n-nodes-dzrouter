#### 0.2.3

- Fix: on n8n 1.x the whole package failed to load with `Cannot find module '@n8n/ai-node-sdk'`. The SDK is now loaded only when the Chat Model runs, and is an optional peer dependency.
- The DzRouter node works on n8n 1.x (tested on 1.115.2); on 1.x the DzRouter Chat Model explains how to use n8n's built-in OpenAI Chat Model with DzRouter instead.
- Node connection types fall back to their plain values on n8n releases older than 1.85.
- Pulses: costs, balances and model prices are reported in Pulses, DzRouter's AI credit (1 Pulse = 1 DA).
